# IcebornToolTracker

Planned dedicated tracker for specialized tools in Iceborne.

Planning repository for specialized-tool duration and recharge using [IcebornSuiteCore](https://github.com/EnzoAlzueta/IcebornSuiteCore). The first milestone is verification of tool lifecycle and timer readings.
