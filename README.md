# Iceborn Tool Tracker

[![Ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/imkyril)

A planned Iceborn Suite panel for specialized tools in Monster Hunter World: Iceborne.

**Project status — planning.** The first milestone is to verify tool activation, expiry and recharge on build 421810. Which tools can be displayed depends on those observations.

## Planned features

- Investigate active duration and recharge for mantles and boosters.
- Display verified tool states through the shared Core HUD.

## Requirements and scope

The proposed panel uses Iceborn Suite Core. Buff Tracker already provides a separate timer panel for Might Seed, Rocksteady Mantle and Temporal Mantle.

## Development

See the [roadmap](ROADMAP.md) for the first milestone and its acceptance criteria. For the related mod, see [Iceborn Buff Tracker](https://github.com/EnzoAlzueta/IcebornBuffTracker).

## Availability

There is no installable build or gameplay validation yet.
